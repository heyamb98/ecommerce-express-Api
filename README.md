# E-commerce REST API

A fully functional RESTful API for an E-commerce platform built with Node.js, Express, and Neon PostgreSQL.

## Features
- Full CRUD operations for Products, Categories, and Users.
- Integrated with Neon PostgreSQL database.
- Centralized error handling middleware.

## Prerequisites
- Node.js installed
- Neon PostgreSQL connection string
